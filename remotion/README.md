# MindMesh Promo Video (Remotion)

1080×700 · 30fps · ~37.3s (1120 frames) · 8 scenes

## Quick start

```bash
cd remotion
npm install
npm run studio
```

Preview the `MindMeshPromo` composition in Remotion Studio.

## Render MP4

1. Add background music: `public/audio/ambient.mp3` (see `public/audio/README.md`)
2. Run:

```bash
npm run render
```

Output: `out/mindmesh-promo.mp4`
